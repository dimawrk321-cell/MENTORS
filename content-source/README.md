# content-source — входные данные точечных прогонов

Здесь лежат исходники, которые нужны закоммиченным скриптам из `scripts/`, чтобы
прогон можно было **повторить**. Без входного файла скрипт в репозитории
невоспроизводим — ровно та дыра, из-за которой число «19» из `suggestions.md`
жило на одной машине, а решения по нему принимались как по факту.

Это не «сырые экспорты» — большие выгрузки (`notion-export.md`, `/import/`)
остаются вне git по прежним правилам. Сюда кладём только компактные входы
точечных операций над контентом.

| Файл                                                           | Кем используется                                                                                                                                                                         |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Python_для_Senior_ML_Engineer_—_вопросы_и_понятные_ответы.md` | `scripts/apply-python-answers.ts --file=…` — замена эталонов 52 Python-вопросов (заход «Эталоны Python»); он же источник новых формулировок для `scripts/apply-python-question-texts.ts` |
